書くときの決まり：数字は公式サイト・メーカー発表・お店の表示に合わせ、出どころを note に書く。
比較表は `"labeled": true` をつけて、左の列が折り返されないようにする。下には products でそのジャンルの1位を出す。

冒頭は、ひとり暮らしの具体的な場面から始める（例：「冬の夜に停電。部屋は真っ暗、暖房も止まる。スマホの電池は残り20%」）。
数字（残り20%、足先が冷たい、火がつくまでの数十秒）を入れて、読む人が自分のこととして思い浮かべられるようにする。

## 暖房費をおさえる記事（「安く」「省エネ」「電気代」の検索が多い）

| 順 | 記事 | ねらい |
|---|---|---|
| A ✓ | エアコン暖房は、つけっぱなしとこまめに消すのどっちが安い？ | 冬の定番の疑問。検索がとても多い |
| B ✓ | 窓の断熱シートは効果ある？ひとり暮らしの寒さ・暖房費対策 | 安く始められる。楽天の商品とつなげやすい |
| C ✓ | 暖房の設定温度、1℃下げるといくら節約？ | 数字で答えられる。暖房費ランキング（hitorigurashi-danbou-yasui）とつながる |
| D ✓ | ひとり暮らしの冬の電気代、平均はいくら？ | 「12月の電気代が高い」と思った人が調べる言葉 |

電力会社の切り替え（A8に広告あり・報酬大きめ）は、提携できたら D の記事などに入れる。

次に書く順：D（冬の電気代の平均・総務省の家計調査で単身世帯の月別電気代。最後に service: "denki-minaoshi" でエネピと電気チョイス）→ A → B → C

暮らし方で答えが変わる記事（比較・電気代・防災）には、「もしも、こんな場合なら」の枠（section の "cases": [{"if": "...", "then": "..."}]）を入れて、在宅ワーク・寒い地域・賃貸・停電2日などの具体的な場面と数字で答える。
